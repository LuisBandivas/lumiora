# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues at `LuisBandivas/lumiora`. Use the `gh` CLI for all operations.

## Conventions

- Create issues with `gh issue create --title "..." --body-file <file>`.
- Read issues with `gh issue view <number> --comments`.
- List issues with `gh issue list` and the appropriate state or label filters.
- Comment, label, or close issues with the corresponding `gh issue` commands.

When a skill says to publish to the issue tracker, create a GitHub issue. When it says to fetch a ticket, run `gh issue view <number> --comments`.

**PRs as a request surface: no.**
