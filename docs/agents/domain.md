# Domain docs

This is a single-context repository. Before exploring a domain, read the root `CONTEXT.md` and relevant decisions in `docs/adr/` when present. Use the glossary's vocabulary in specs and tests. If a needed term is missing, note the domain language gap and update the glossary when the term is resolved.

Missing context or ADR files are not blockers. Create them only when a domain term or a material, hard-to-reverse decision needs recording.
